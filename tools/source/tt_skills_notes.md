# tt_skills.json: extraction notes and judgment calls

Source: `naigc-dd-charts.pdf`, 4 pages. Page 1 is Trampoline (updated 7/29/24), page 2 is Double Mini (8/13/25), page 3 is Tumbling (11/22/25), and page 4 is the NAIGC addendum.
Generated by `build_tt.py` (same folder). Every DD and FIG number on pages 1–3 was cross-checked by script against the PDF text layer, row by row for Trampoline and DMT. Every number on page 4 was checked as a multiset.

Counts: tramp 101 (57 chart + 44 addendum), dmt 46 (40 chart + 6 addendum), tumbling 74 (53 chart + 21 addendum-only; 4 chart skills overridden by the addendum).

## Needs a decision
1. **DMT jump value conflict.** The page-2 header says "Tuck, pike and straddle jumps will be worth 0.1 DD each". The NAIGC addendum's DMT table lists Tuck Jump, Straddle Jump and Pike Jump at **0.0**. **The skill list uses 0.1**, for these reasons:
   - The addendum overrides only struck-through values, and page 2 has no strikethroughs (verified).
   - Page 2 is dated 8/13/25.
   - The DMT addendum rows look copied, value for value, from the first six trampoline addendum rows.
   - The code of points' DMT section treats a straddle jump as a skill that can earn difficulty. Its repeat rule uses "Mounter Straddle Jump" as an example, and Intermediate Flyers have "4 counting skills".

   The flagged header sentence is in `rules.dmt`. If the addendum's 0.0 is intended, change those three DMT entries. Trampoline jumps stay 0.0, because the struck page-1 rule is replaced there by the addendum.

## Strikethrough overrides (verified: exactly 5 struck items in the PDF)
- Page 1: rule "Elements without twist or somersault 0.1". It is replaced by the addendum's itemized jump/drop/turn skills. It is kept in `rules.tramp` with a "[Struck through…]" prefix so it isn't lost, and it should not be applied.
- Page 3: Roundoff 0.1→**0.2**, Front handspring 0.1→**0.2**, Back handspring 0.1→**0.2**, Whipback 0.2→**0.3**. These are merged into the single page-3 entry.
  - Symbols are taken from page 3 (`(`, `H`, `F`, `^`). The addendum prints different ones: Roundoff `{`, Front Handspring `f`, Back Handspring `f`. Back handspring and front handspring sharing `f` looks like an addendum typo.

## Shape / format decisions
- **Tumbling `alt_symbol`.** This key is an extension of the requested shape. Page 3 gives two notations for many singles (e.g. Front somersault tuck `.4o` *or* `.-o`). `symbol` holds the first (left-hand) notation and `alt_symbol` holds the second. The key is present only where the chart shows an "or" alternative.
- Tumbling symbols are whitespace-stripped (`. - - o` → `.--o`, `. 4 o` → `.4o`). Cyrillic "о" and modifier "˄" from the PDF text layer are normalized to ASCII `o` and `^`. All `fig`/`symbol` values are ASCII.
- **Blank DMT cells are omitted, not null or 0.** The affected skills are Full-in, full-out (no pike); Double full, double full (no pike); Triple full, double full (straight only); all front triples and Triffis full-in / half-in triples (no straight); and Quad back (no straight).
- **All addendum trampoline/DMT skills use positions key `""`.** The addendum gives one DD regardless of shape (e.g. "Front Drop (all positions)"). This includes **Pullover to Back** (FIG `4-o`, 0.5), even though its FIG shows a tuck; it could arguably be `{"o": 0.5}`.
- **FIGs are kept as printed on the addendum**, even where the task example differed. Seat Drop is `"--/"`, not `""`. Doggy Drop is `"Doggy"`, Straddle Jump is `"Straddle"` and Return to Feet is `"ROF"`. Back Extension Roll Pike Down has no symbol printed, so it is `""`.
- Pike jump, Forward Roll (pike) and Backward Roll (pike) are printed with FIG `-->`. Pike is normally `<`, so `--<` was probably intended. It is kept as printed.
- **Arabian (tumbling addendum)** is printed as one row with symbols `41o` / `41<` and DD 0.7. It is split into "Arabian (tuck)" `41o` and "Arabian (pike)" `41<`, both 0.7, matching how page 3 lists tuck and pike as separate rows.
- **Duplicate Pullover.** The addendum's "Pullover" (`3-/`, 0.3) duplicates page-1 "Pullover" (FIG `30`, 0.3 in all positions). Only the page-1 entry is kept.
- Names are kept as printed, including nicknames in quotes: "Full, double full 'Miller'", and on DMT "1½ in, half-out 'Full, full'". The 'Full, full' nickname on FIG 831 looks odd but is as printed. Names are unique within each event. There is no front/back direction field; direction is implied by the name. Some front and back skills share a FIG number, e.g. tramp front "Double Front" and back "Double back" are both 800.

- **FIG / symbol strings are not unique keys, so look skills up by `name`.**
  - Tumbling `--o` is used for Double back tuck, Forward Roll (tuck), Backward Roll (tuck) and Forward Roll Step-Out.
  - Tumbling `--/` is both Double back straight and Straight Jump/Rebound. `-1/` is Back half-out straight and Jump 1/2 Turn. `-2/` is Full-out straight and Jump Full Turn. `^` is Whipback and Forward Whip.
  - Trampoline FIGs repeat across many rows (`-1/`, `11/`, `1-/`, `800` front and back, and others).

## Printed oddities kept as-is
- Tumbling "Full, double full tuck/straight" has symbol `33o` / `33/` (which reads as 1½-in, 1½-out). It is kept as printed.
- DMT front-side FIG 821 is named "Full-in, half-out"; on the trampoline page 821 is "Full-in, Barani-out".
- Trampoline Barani: pike 0.6 = tuck 0.6. This is consistent with the "no twist" pike-bonus rule.

## Rules text
- **Two page-1 rules are truncated in the source PDF text and visually.**
  - "Double somersaults — each ½ (180°) twist over…": back-solving from FIGs 813/815/822/823/825/833/844 gives a threshold of 720° (more than 2 full twists).
  - "Triple somersaults — each ½ (180°) twist over 3…": back-solving from FIGs 12003/12101/12103/12203/12222 gives 360°. All listed values fit.
  - "Pike / straight in single somersault, no…" is inferred as "no twist".
  - Each inference is marked inline with "[truncated in source; … inferred …]".
- Tumbling page 3 does not print the base somersault values. A bracketed note gives the implied values: single 0.5; double 1.0 before ×2.
- **Hidden text excluded.** The PDF text layer contains bonus text that is covered up and not visible on the rendered pages, so it is not in `rules`:
  - Page 1: "Women: Bonus for more than 2 triple somersaults 0.3 ea" and "Men: Bonus for more than 5 triple somersaults 0.3 ea".
  - Page 3: a "Special Bonus" block (IE/SR men 2nd+ element min 4.4 DD: 1.0 bonus; Women & YE/JR men 2nd+ element min 2.0 DD: 2.0 bonus) and "Elite & Development Programs: No more than 3 fulls will receive DD in each routine."
  - These look like USAG-only content that NAIGC blanked out. Related: the NAIGC code of points separately says fulls may be performed up to 3 times per pass to earn difficulty.
